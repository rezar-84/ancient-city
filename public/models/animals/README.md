# Market sheep

`sheep.obj` is the Sheep OBJ from the user-provided “Farm Animals Animated by Quaternius” pack (2018). The source pack contains no license file; the model is credited to Quaternius in the application. The OBJ is loaded only in ancient walk mode. Its two source material groups use lightweight, shared runtime materials. The original FBX animation was not imported; the market sheep turn gently in place.
